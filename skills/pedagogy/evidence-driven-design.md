# Evidence-Driven Design

Course success must be measurable. Every artifact generated should include hooks
for gathering evidence:

- **Assignments:** prompt students to report quantitative metrics (code coverage %,
  CI/CD pass rate, linter score).
- **Team projects:** include reflection questions in `CONTRIBUTIONS.md` to capture
  qualitative process data.
- **Lecture notes:** include "Instructor Prompts" — high-level questions that surface
  student understanding of trade-offs in the [course domain].

**HIL awareness:** When generating an artifact with evidence hooks, note in the HIL
block which metrics the instructor should verify are collectable before publishing.
