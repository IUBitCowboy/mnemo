# Cognitive Load Management

- **One Concept Per Slide** rule for slide decks.
- For complex assignments or exercises, proactively suggest **Starter Code** to
  eliminate setup friction.
- Provide a **Worked Example** of a similar problem before asking students to
  attempt the real one.

These techniques reduce cognitive load so students can focus on the core learning
objective rather than setup, boilerplate, or simultaneously processing multiple
new concepts.
