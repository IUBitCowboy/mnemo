# CONTRIBUTIONS.md Log Entry Format

Every team-based exercise must include a `CONTRIBUTIONS.md` entry block using
this exact format:

```markdown
# [Exercise N]: [Exercise Title]
* **Date:** YYYY-MM-DD
* **Team Members Present:** `@github-user1`, `@github-user2`, ...
* **Roles:**
    * Repo Admin: `@github-userX`
    * Process Lead: `@github-userY`
    * Dev Lead: `@github-userZ`
    * QA Sentinel: `@github-userW`
* **Summary of Work:** [1-2 sentences on what was accomplished]
* **Evidence & Reflection:** [Exercise-specific open-ended question inserted here]
```

The `Evidence & Reflection` question is exercise-specific — it should prompt
qualitative reflection on the engineering process, not just report what was done.
This is a key evidence-gathering mechanism for the Evidence-Driven Design pillar.

When generating an exercise, propose **4 candidate questions** for the
Evidence & Reflection prompt. Present each as a single question. The
instructor may:

- Select one of the 4 candidates
- Reject all 4 and ask you to try again
- Provide their own question for you to insert

Do not skip this step — the reflection question is the instructor's opportunity
to steer the learning outcome of the exercise.
