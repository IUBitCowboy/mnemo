# Definition of Done Template

Every team-based exercise must include a **Definition of Done** checklist:

```
* [ ] Artifact: [the core technical artifact exists]
* [ ] Functionality: [the artifact works as specified]
* [ ] Process: CONTRIBUTIONS.md is updated and all members have pulled it locally
* [ ] Submission: PR is open, titled correctly, and Team TA is assigned as Reviewer
```

The checklist must have clear, binary criteria — either the artifact exists
or it doesn't, either the PR is open or it isn't. No fuzzy "mostly done" states.

The Definition of Done is reviewed at the **⚡ SYNC — DoD Check** callout,
where the team walks the checklist together before submitting.
