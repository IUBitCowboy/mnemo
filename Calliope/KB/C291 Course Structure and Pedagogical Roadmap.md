# C291 COURSE STRUCTURE & LOGISTICS

## 1. Course Overview
- **Title:** C291 System Programming with C and Linux
- **Duration:** 15 Weeks (Starting Jan 12)
- **Schedule:** Twice weekly, 75-minute sessions.
- **Break:** Spring Break occurs between Week 9 and Week 10.
- **Final Capstone:** A functional "Simple Shell" written in C, due Week 15.

## 2. Student Profile (The Starting Line)
- **Prerequisites:** Completion of CSCI-A 201, C 200, C 211, or INFO-I 211.
- **Prior Knowledge:** Basic programming logic in high-level languages (Java/Python) using modern IDEs (VS Code/PyCharm/IntelliJ).
- **Assumed Gaps:** Students have ZERO experience with:
    - Manual memory management (pointers/malloc).
    - The Linux Command Line Interface (CLI).
    - Text-based editors (Vim/Nano).
    - Low-level compilation (GCC/Make).
- **Instructional Note:** All materials must bridge the gap from "High-Level/Safe" programming to "Low-Level/Systems" programming.

## 3. Weekly Instructional Rhythm
Every week generated by the Gem must include:
1. **Class 1 & 2 Material:** 50% Lecture/Demo, 50% In-Class Exercise (ICEX).
2. **ICEX (In-Class Exercise):** High-engagement, hands-on coding.
3. **Weekly Out-of-Class Program:** A standalone C program that builds on the week’s concepts.
4. **Weekly Assessment:** One out-of-class exercise or quiz.

## 4. The Shell Milestone Track
The course is an incremental build toward the Week 15 "Simple Shell." 
- **Phase 1 (Weeks 1-5):** Tools, Syntax, and Pointers.
- **Phase 2 (Weeks 6-9):** Memory Management, Structs, and File I/O.
- **Phase 3 (Weeks 10-15):** Processes (fork/exec), Signals, and IPC (The Shell Components).

## 5. Pedagogical Requirements
- **Theory-Driven Debugging:** All lab/assignment instructions must prompt the student to theorize before they edit.
- **AI-Learning Integration:** Every assignment must include a section on how to use AI to clarify that specific week's concepts without bypassing the coding logic.
