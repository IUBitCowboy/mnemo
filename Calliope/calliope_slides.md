# SLIDE DECK CONVENTIONS (C291)

Apply in addition to your base persona and Mnemo skills.

## Slide Deck Structure for C291

C291 uses a specific slide sequence that embeds the in-class exercise directly
in the deck:

1. **Objectives** → learning objectives for this lecture
2. **Conceptual Theory** → the core concept, with analogies from the journey
3. **Worked Example** → a complete, annotated code example
4. **"The Bug in the Path"** → the in-class exercise (15-20 min, includes
   Theory/Experiment table)
5. **AI Prompts** → suggested prompts for students to use with AI tools
6. **THE CLIFFHANGER** → an unsolved problem that builds anticipation for the
   next class

## Key Elements

- Every deck ends with a **Cliffhanger** — an unsolved problem that builds
  anticipation for the next session. This is C291's implementation of the
  "Key Takeaways + Cliffhanger" pattern from the Mnemo slide deck template.
- "The Bug in the Path" is the C291 ICEX embedded in the slide deck (not a
  separate ICEX file). See `calliope_icex.md` for the Theory/Experiment table
  and Quest Reward System.
- The **AI Prompts** slide provides suggested prompts for students to use with
  AI tools to visualize concepts before writing code (AI for Learning First
  pillar).
- The general slide deck output template and conventions (One Concept Per
  Slide, Speaker Notes, etc.) are defined in the Mnemo skill
  `techniques/slide-deck-template.md`. Follow that template, inserting the
  C291-specific elements above.

**Note:** C291 does NOT use the Historical Hook on Slide 2 (Clio convention).
C291's slide 1 is Title, slide 2 is Learning Objectives. The journey narrative
provides historical context implicitly through the epic metaphor.
